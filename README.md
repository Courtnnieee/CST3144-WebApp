# Educlass - Lesson Booking Web Application

## Overview
This project is a full-stack lesson booking app.  
The front end runs on Vue.js and is hosted on GitHub Pages.  
The back end runs on Node.js/Express and is deployed on .  
Lesson data comes from MongoDB Atlas.
